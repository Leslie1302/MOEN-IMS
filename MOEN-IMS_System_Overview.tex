% --- 1. Purpose ---
\section{1. Purpose}
MOEN-IMS is a web-based platform that manages and tracks construction and project
materials across their full lifecycle — from warehouse stock through requisition,
approval, transport, and confirmed delivery to site. It replaces paper-based forms,
telephone coordination, and disconnected spreadsheets with a single system that gives
every stakeholder a shared, real-time view of material movements and an auditable
record of every transaction.

% --- 3. Technology & Architecture ---
\section{3. Technology and Architecture}
The system is built on the Django (Python) web framework using a Model–View–Template
architecture, with a PostgreSQL database in production. The application follows a
signal-based design so that notifications, status updates, and audit entries are
generated automatically as records change.

\begin{itemize}
  \item \textbf{Backend:} Django 5.1 (Python), served via Gunicorn.
  \item \textbf{Database:} PostgreSQL (SQLite for development).
  \item \textbf{Frontend:} HTML, CSS/Bootstrap, and JavaScript; responsive on desktop and mobile.
  \item \textbf{Data \& reporting:} pandas and openpyxl for Excel import/export; ReportLab, Plotly and Matplotlib for PDF reports and dashboards.
  \item \textbf{Supporting services:} QR-code generation and verification, Microsoft 365 e-mail notifications, and one-time-password (OTP) two-factor authentication.
\end{itemize}

% --- 5. Core Capabilities ---
\section{5. Core Capabilities}
\begin{itemize}
  \item \textbf{Material request workflow:} digital requisitions with unique tracking codes moving through a Draft $\rightarrow$ Pending $\rightarrow$ Approved $\rightarrow$ Completed lifecycle.
  \item \textbf{Inventory dashboard:} real-time stock levels with colour-coded low-stock alerts.
  \item \textbf{Transport management:} approved transporter and vehicle records, with status tracking from Assigned $\rightarrow$ In Transit $\rightarrow$ Delivered.
  \item \textbf{Waybill generation:} automatic, uniquely numbered waybills carrying QR codes for on-the-spot verification.
  \item \textbf{Budget (BOQ) control:} requests checked against Bill of Quantities allocations, with automatic detection and controlled approval of over-issuance.
  \item \textbf{Site receipt confirmation:} consultants log delivery, condition, and any discrepancies as digital proof of receipt.
  \item \textbf{Reporting:} automated weekly and management reports exported to PDF and Excel.
  \item \textbf{Bulk operations:} bulk transporter assignment and consignment tracking for multi-order deliveries.
\end{itemize}

% --- 6. Security & Controls ---
\section{6. Security and Controls}
The platform applies layered, industry-standard controls to protect data and
ensure accountability:

\begin{itemize}
  \item Role-based access control and session management.
  \item Two-factor authentication (OTP) and strong password hashing.
  \item Protection against SQL injection, cross-site scripting (XSS), cross-site request forgery (CSRF), and clickjacking.
  \item Encrypted transport (SSL/HTTPS) and validated file uploads.
  \item QR-verified waybills and cryptographic digital signature stamps to deter fraud and forgery.
  \item Complete audit trail of user actions for regulatory compliance.
\end{itemize}

% --- 7. Current Status ---
\section{7. Current Status and Outlook}
The core system is operational in production, with an enhanced feature set —
including assigned-order stores management, QR digital waybills, digital signature
stamps, BOQ over-issuance controls, performance dashboards, and automated reporting —
being deployed in phases. The cloud-based architecture is designed to scale with
demand, and planned next steps include an offline mode for low-connectivity sites
and API integration with accounting systems.
